## 2025-02-17 - Unhandled Rejections and SDK Context Scope Leakage in Catalyst Express Functions
**Vulnerability:** Uninitialized Catalyst SDK instance (`catalyst.initialize(req)` missing across controller endpoints) alongside missing `express.json()` body parsing and absence of `try...catch` error handling caused server crashes, hanging requests, and unvalidated payload updates.
**Learning:** In Zoho Catalyst serverless Express functions, failure to initialize the SDK context per request leads to `ReferenceError` runtime crashes or cross-tenant scope issues. Without explicit body parsing middleware and input validation (`ROWID` check), malformed or unexpected payloads bypass checks or cause unhandled rejections.
**Prevention:** Always initialize `catalyst.initialize(req)` inside request handlers, enable `express.json()` middleware at app entry, validate expected properties on `req.body` or `req.params`, and wrap async operations in `try...catch` blocks returning generic HTTP error status responses.
