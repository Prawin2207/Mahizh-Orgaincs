## 2026-08-12 - Zoho Catalyst SDK Global Scope Reference Error & Unsanitized Row Updates
**Vulnerability:** Global context leakage, missing input sanitization, and unhandled promise rejections in Zoho Catalyst serverless handlers.
**Learning:** In Zoho Catalyst Express functions, assigning the SDK context to a global or poorly scoped variable can cause reference errors when other request handlers run. Additionally, passing the raw `req.body` directly to `table.updateRow()` without schema-based key sanitization exposes the application to parameter pollution and unauthorized attribute manipulation. A lack of try-catch wrapper blocks can also lead to unhandled promise rejections that crash or stall the server.
**Prevention:** Always initialize the Catalyst SDK instance within each request handler scope using `const app = catalyst.initialize(req)`. Explicitly validate inputs and filter properties in `req.body` against a strict whitelist of allowed fields. Wrap all database and filestore asynchronous actions in robust `try-catch` blocks and return explicit HTTP status codes/responses.
