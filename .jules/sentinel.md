## 2026-10-19 - Unhandled Async Rejections and Reference Errors in Express Controller Handlers
**Vulnerability:** Unhandled asynchronous errors and missing request context initialization in Zoho Catalyst Express backend function endpoints caused unhandled promise rejections and potential internal stack trace leakage.
**Learning:** In Zoho Catalyst Node.js Express serverless functions, initializing SDK application context globally leads to runtime `ReferenceError`s in un-scoped router actions. Furthermore, unhandled async exceptions in Express route handlers can cause server instability or expose sensitive internal application details if not wrapped in `try-catch` blocks returning generic HTTP 500 error responses.
**Prevention:** Always initialize `catalyst.initialize(req)` per request inside route handlers, wrap async database/filestore operations in `try-catch` blocks with sanitized error responses, and ensure middleware such as `express.json()` is configured for request body parsing.
